    What happens when you click

    1. The API validates the request, reserves capacity on the best-fit host and records a queued operation, all in one database transaction, then answers 202 Accepted.
    2. A worker claims the operation under a lease and calls the provider with a deadline. Failures are retried with exponential backoff and jitter; a crashed worker's lease expires and the work is re-queued.
    3. The result is committed with a version check, so a stale outcome can never overwrite newer state, and every step is written to the audit trail.
    4. A reconciler compares recorded state with what the provider reports and repairs or flags drift.
